# NotX Labs

Technology, built to a global standard.

NotX Labs is a technology company based in Nigeria building software products
to a global standard: Sparks (messaging), Qovu (verified attendance),
Submitiv (deadline-controlled submissions) and Social AI Studio
(approval-first AI social content, in development).

Website: https://notx-labs.vercel.app/

- `index.html` — the company website (single self-contained page)
- `robots.txt`, `sitemap.xml`, `llms.txt` — SEO and AI-search files, served from the site root
- `assets/` — the NotX Labs N mark (favicon and app icon)
